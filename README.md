# evtol-project

Diseño conceptual propio de un eVTOL: requisitos, dimensionamiento, geometría, CAD, planos, prototipo a escala y app web interactiva.

El objetivo, las reglas y los libros de referencia están en [`CLAUDE.md`](CLAUDE.md). Los requisitos y las decisiones, en [`docs/`](docs/).

## Cálculos en Python

```bash
pip install -r requirements.txt
pytest
```
